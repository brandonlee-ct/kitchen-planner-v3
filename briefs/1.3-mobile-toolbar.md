## Context
This is the Brown Box Kit 3D kitchen planner (vanilla JS + three.js, no framework).
Read `AGENTS.md` first and follow every house rule. The app runs on desktop, iPad,
iPhone, and Android. The top toolbar markup is in `index.html` (`#toolbar`), styled in
`style.css`, with handlers in `main.js`. Note `#toolbar` now has both **Draw Wall** and
**Free Draw** buttons — keep both reachable on mobile.

## Goal
Make the top toolbar work well on mobile without harming desktop.

## Requirements
1. **44px touch targets** — toolbar buttons become at least 44×44px square on touch/mobile
   widths. Keep the desktop appearance essentially unchanged at wide widths.
2. **☰ Hamburger menu** — on small screens (≤768px tablet, and especially ≤430px iPhone),
   collapse secondary toolbar actions behind a ☰ button that opens a simple menu/drawer.
   Primary actions (Draw Wall, 2D/3D toggle) should stay reachable. Use existing element
   IDs; add new IDs only as needed and wire them in `main.js`.
3. **📷 Camera capture** — add a camera button that saves a PNG snapshot of the current
   `#canvas` view (use `renderer.domElement.toDataURL('image/png')` and trigger a download,
   filename e.g. `kitchen-view.png`). Works on desktop and mobile.

## Constraints (must obey)
- Do NOT refactor existing code or rename existing functions/IDs.
- Touch AND mouse paths must both keep working.
- Respect existing CSS breakpoints: **430px (iPhone)** and **768px (tablet)**. Do not add
  new breakpoints without reason.
- Do not change `walls` / `placedItems` state, history-entry shape, or any function signature.
- Undo/redo must remain intact.

## Files you'll likely touch
