## Context (existing quote/export code)
- `updateQuote()` (in `main.js`) computes the on-screen total.
- The CSV export handler on `#btn-export` builds line items from `placedItems`:
  for each placed item with `userData.product.skus`, it reads
  `product.name`, `product.skus[skuIndex ?? 0].label`, and `.price`, summing the total.
  Prices are NZD. Use the SAME data source so the PDF total matches the CSV/on-screen total.

## Goal
Add a "Download PDF" quote that produces a clean, branded PDF a customer can keep:
project name, date, line items, and grand total in NZD.

## Steps
1. **Add a PDF lib via the package manager:** `npm i jspdf` (and `jspdf-autotable` if helpful).
   Import it where the export handlers live. Do not hand-roll PDF bytes.
2. **Add a button** `#btn-export-pdf` next to the existing CSV export button in `index.html`
   (e.g. label "Download PDF"); wire a handler in `main.js`.
3. **Build the quote** from `placedItems` (same logic as the CSV handler), but **aggregate
   identical SKUs into a quantity line**: columns = Product | SKU/Variant | Qty | Unit (NZD) |
   Line Total (NZD). Add a **Grand Total (NZD)** row. Include project name (from the save name
   field if available, else "Kitchen Quote") and today's date. A simple "Brown Box Kit" header
   is enough (no logo needed).
4. **Download** as `kitchen-quote.pdf` (mirror the CSV handler's download approach).
5. (Optional, only if easy) include a small canvas snapshot
   (`renderer.domElement.toDataURL('image/png')`) at the top of the PDF.
