## What ALREADY exists (DO NOT invent a schema — use these)
The `projects` table already has, from a security migration:
- `is_public boolean not null default false`
- `share_slug text unique`
- RLS policy `projects_select_public`: `for select using (is_public = true)` (lets anyone,
  including anonymous, SELECT rows where `is_public = true`).
Owner read/write policies also exist. `auth.js` has `loadProject(id)` which filters by
`user_id` (owner-only) — you will add a SEPARATE function for the public path.

## Step 1 — PLAN ONLY, then STOP for approval
Write (in the PR description, do NOT implement yet) your plan covering:
- **Share token:** confirm using `share_slug` as a random, unguessable token
  (e.g. `crypto.randomUUID()` or 16+ random chars), NOT a sequential id. Share URL shape:
  `${location.origin}/?p=<share_slug>` (query param — no server routing needed for this SPA).
- **The security decision (state both options + your recommendation, then WAIT):**
  - **Option A (simple):** keep the existing broad `projects_select_public` policy. Risk: with
    the public anon key, someone could query `projects where is_public = true` and **enumerate
    ALL shared projects** (not just ones they have a slug for). Acceptable only if shared
    designs are considered non-sensitive.
  - **Option B (recommended, no enumeration):** replace the broad policy with a
    `security definer` RPC `get_shared_project(slug text)` that returns a single row by
    `share_slug`, and DROP `projects_select_public` so anon cannot list public rows. Clients
    can only fetch a project if they know its slug.
  - Recommend Option B unless the human says otherwise. **Stop and wait for "approved".**

## Step 2 — Implement (only after approval)
Per the approved option:
- **Owner side:** a "Share" toggle on a saved project that sets `is_public = true` and generates
  a `share_slug` if missing (via `updateProject` or a small new helper), shows the copyable link,
  and an "unshare" that sets `is_public = false`.
- **Public side:** a new `auth.js` function — `loadSharedProject(slug)` (Option A: select by
  `share_slug`, no `user_id` filter; Option B: call the RPC). On page load, if `?p=<slug>` is
  present, load that project **READ-ONLY**: render the scene, but hide/disable Save, editing,
  and drawing for non-owners. Must work when NOT signed in (uses the anon key + RLS/RPC).

## Acceptance criteria

- [ ] Unsharing makes the link stop working.
- [ ] `share_slug` is random/unguessable; the chosen option's anti-enumeration stance is honored.
- [ ] Owner's normal `loadProject(id)` and all existing flows unchanged.
