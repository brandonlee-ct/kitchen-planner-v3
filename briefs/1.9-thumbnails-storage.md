## Context
Supabase auth + a `projects` table (`scene_json` jsonb, `thumbnail` text, keyed by `user_id`).
- `serialiseScene()` in `main.js` returns `{ sceneJson, thumbnail, ... }` where
  `thumbnail = renderer.domElement.toDataURL('image/png')` (a big base64 **data URL**).
- The Save handler (`#btn-save-project`) calls `saveProject(name, sceneJson, thumbnail)`
  (and there is `updateProject(...)`) in `auth.js`, storing the string into `projects.thumbnail`.
- `listProjects()` renders `row.thumbnail` as an `<img src>`.
- A public Storage bucket **`thumbnails`** already exists, with RLS policies: public read;
  owner insert/update/delete where `owner = auth.uid()`. (Created already — do not recreate.)

## The change (small blast radius)
Store the PNG in the `thumbnails` bucket and save the **public URL** in `projects.thumbnail`,
instead of a multi-hundred-KB base64 string. **The `thumbnail` column stays a URL string —
only the storage location changes (data URL → Supabase Storage public URL).**

## Steps
1. **Add an upload helper in `auth.js`** (exported), e.g. `uploadThumbnail(dataUrl)`:
   - Convert the data URL to a Blob/Uint8Array.
   - `path = `${_user.id}/${crypto.randomUUID()}.png``.
   - `await _client.storage.from('thumbnails').upload(path, blob, { upsert: true, contentType: 'image/png' })`.
   - On success return `_client.storage.from('thumbnails').getPublicUrl(path).data.publicUrl`.
   - On any error, **return null** (caller falls back — saving must never break).
2. **Wire it into the Save flow** (in `main.js`'s `#btn-save-project` handler, and any update path):
   after `serialiseScene()`, if signed in, `const url = await uploadThumbnail(thumbnail)`; pass
   `url ?? thumbnail` as the thumbnail argument to `saveProject` / `updateProject`. (Fallback to
   the data URL keeps save working if storage hiccups.)
3. **Backward compatibility:** do NOT migrate old rows. `listProjects()` already does `<img src=row.thumbnail>`,
   which works for both `data:` and `https:` URLs. Confirm both render.

## Acceptance criteria
